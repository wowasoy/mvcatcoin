# Contributing

## Setup

    git clone --recursive https://github.com/wowasoy/mvcatcoin.git
    cd mvcatcoin
    forge install

## Frontend

    cd frontend
    npm install

## Workflow

1. Branch from main.
2. Write tests before implementation.
3. Run `forge fmt`, `forge test`, and `npm run typecheck` locally.
4. Open a pull request with a clear description.

## Code Style

- Solidity 0.8.30, NatSpec for public and external functions, custom errors, Checks-Effects-Interactions.
- TypeScript strict mode, no `any`, explicit return types on exported functions.
